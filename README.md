Simple Port Scanner

A simple Python-based Port Scanner project.

Features

- Scan ports on a target host.
- Identify open ports.
- Simple and easy-to-use interface.

Requirements

- Python 3

How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

python port_scanner.py

This tool is intended for educational purposes and authorized security testing only. Scan only systems you own or have permission to test.
